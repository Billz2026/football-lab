# Viktor Kane V46 source provenance

The V46 Viktor Kane authoring workflow uses Blender Studio's **Human Base Meshes** asset bundle as the source topology.

- Source family: Blender Studio Human Base Meshes
- Bundle used by CI: `human-base-meshes-bundle-v1.4.1.zip`
- Licence: Creative Commons CC0 / public-domain dedication for the Human Base Meshes bundle
- Production transformation: Football Lab-specific proportions, materials, humanoid rig, skinning and football animation clips are generated by `scripts/build-viktor-v46.py`.
- Character identity: Viktor Kane is an original Football Lab character. No direct real-person or footballer likeness is used.

The generated `viktor-kane.glb` is a technical master candidate only until it passes the V46 in-game visual approval gate in `game/assets/characters/v1/PRODUCTION-3D-SPEC.md`.
