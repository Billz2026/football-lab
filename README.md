# Football Lab Manager

Football Lab has pivoted from an arcade football project into **Football Lab Manager** — a fast, focused football management simulation inspired by the immediacy of classic management games.

## Current public build

The GitHub Pages homepage now presents the new manager identity and six core entry points:

1. Start New Game
2. Quick Start
3. Load Game
4. Game Settings
5. Hall of Fame
6. Football Database

The previous arcade gameplay is no longer exposed from the public homepage. Its historical code remains in the repository/history while the manager architecture is built.

## Product direction

The first playable management milestone will target one complete league and one complete season with:

- clubs and squads
- player attributes
- fixtures and league table
- tactics and team selection
- text/simulation match engine
- transfers and contracts
- player development
- local save/load support

The priority is a strong core loop before expanding into additional leagues, competitions or secondary systems.
