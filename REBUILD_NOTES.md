# Football Lab arcade rebuild

## Release scope

This rebuild replaces the old laboratory-style landing page with a focused arcade football foundation.

### Playable now

- Classic Kicks three-input control loop: power, placement and curve
- Responsive canvas scene with goalkeeper, wall, wind and shot animation
- Escalating stages, score bonuses, streaks and three-life runs
- Local personal best, best streak, XP and level persistence
- Desktop, mobile and keyboard controls

### Structured for later builds

- Road to Glory career progression
- Score Attack timed mode
- Online daily challenges and leaderboards

The previous set-piece prototype remains in the repository for reference but is no longer linked from the live homepage.
