# Football Lab Manager V0.4.5 — Match Centre

V0.4.5 adds a Championship Manager-inspired match presentation layer while preserving Football Lab's existing interactive match engine.

## Included
- prominent blue live scoreboard and match clock
- match context strip with venue plus deterministic in-game attendance, referee and weather
- Match Overview / Match Stats / Action Zones / Match Report tabs
- central live event banner for goals, bookings, red cards, injuries, substitutions, tactical changes, half-time and full-time
- live match statistics view
- transparent territorial-pressure estimate derived from possession, shots and shots on target
- key-incident match report fed from the actual commentary stream
- lower match navigation for team stats, player ratings, latest scores and live league table
- latest scores for concurrent AI fixtures derived from the same deterministic round simulation as the career engine
- live league table calculated from current match scores
- all existing half-time, tactical, positional-role and substitution controls retained

## Not included
- copyrighted Championship Manager artwork/assets
- fabricated real-world weather, referee or attendance claims; these are deterministic in-game simulation context
- 2D/3D animated match graphics
